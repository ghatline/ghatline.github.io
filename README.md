# Tempo traveller rental website (Bangalore)

A fast, static website for a tempo traveller / Force Urbania rental business in Bengaluru. Plain HTML, CSS and a little vanilla JS. Hosted free on GitHub Pages, with no build step needed to serve it.

**Live (until you add a domain):** https://rahul-sah089.github.io/tempo-traveller-bangalore/

---

## 1. Before you promote the site: replace the placeholders

Search the project for `TODO`. Everything that is a placeholder is marked that way. The important ones:

| What | Where |
|---|---|
| Business name, phone, WhatsApp, email, area, PIN, hours, map location | `assets/js/config.js` → `business` |
| Instagram / Facebook / YouTube / Google Business Profile links | `assets/js/config.js` → `social` |
| Per-km rates, driver bata, minimum km per day | `assets/js/config.js` → `pricing` and each vehicle's `ratePerKm` |
| Luxury 1x1 Maharaja: offer it or not | `assets/js/config.js` → `enabled: false` on that vehicle |
| Vehicle photos | `assets/img/fleet/` (see section 3) |
| Your story | `about/` page (generated from `tools/generate.mjs`, see "About") |
| Real Google reviews | "Reviews" section (never add made-up reviews) |
| Sample tour plans | `tools/generate.mjs` → `pkgs` list |
| Terms and privacy policy | Review them for your business (`tools/generate.mjs`, "LEGAL") |

When your real rates are in, set `ratesAreSample: false` in `config.js`. That hides the "sample rates" note and adds price offers to the vehicle pages' structured data.

Also read through the marketing copy (for example "cleaned before every trip" or "we usually reply within minutes") and change anything that isn't true for your business.

## 2. Editing rates and contact info

1. Open `assets/js/config.js` and edit the values. Comments explain each one.
2. Regenerate the pages so titles, structured data, the sitemap and share tags pick up the changes:

   ```bash
   node tools/generate.mjs
   ```

   You need Node.js 18 or newer. There's nothing to install.
3. Commit and push (section 4). The site updates in about a minute.

Rates, phone and WhatsApp number are also read live by the browser from `config.js`. If you only change a rate, pushing `config.js` alone is enough. Regenerating is still recommended.

**How the fare estimator works:** fare = the higher of (round-trip km) or (`minKmPerDay` × days), × the vehicle's per-km rate, + `driverBata` × days. Tolls, parking, permits and GST are shown as extra. It is labelled "indicative" everywhere.

Destination distances, drive times, seasons and places are in the `destinations` list in `config.js`. Distances are approximate one-way road figures from central Bengaluru. Correct them from your own trip sheets if they differ.

## 3. Replacing images

- **Vehicle photos:** replace `assets/img/fleet/urbania-960.webp`, `traveller-960.webp`, `maharaja-960.webp` (960×640) and the matching `-480.webp` files (480×320) with your own photos, keeping the same file names. Use only photos of **your own** vehicles. Convert JPG to WebP with https://squoosh.app (quality about 75).
- **Hero illustration:** the ghat-road van on the home page is an inline SVG drawing. You can keep it, or replace it with your own photo (see the TODO in `tools/generate.mjs`).
- **Instagram tiles:** six placeholder tiles in the "Follow our trips" section (TODO in `tools/generate.mjs`).
- **Share images (OG cards), favicons and placeholders** are generated by `tools/make-images.mjs`. Re-run it after you change the business name or phone so link previews show the right details:

  ```bash
  mkdir og-tools && cd og-tools
  npm init -y && npm i playwright sharp && npx playwright install chromium
  node ../tools/make-images.mjs ..
  ```

  (Delete the `og-tools` folder afterwards, or keep it out of git. It's in `.gitignore`.)

## 4. Deploying on GitHub Pages

This repo is already set up for Pages: `index.html` in the root, `.nojekyll`, relative paths, and a custom `404.html`.

To publish changes:

```bash
git add -A
git commit -m "Update rates"
git push
```

Pages settings (already done for this repo): **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`**.

## 5. Custom domain (e.g. `yourdomain.in`)

1. In `assets/js/config.js`, set `siteUrl: "https://yourdomain.in"` and run `node tools/generate.mjs`.
2. Create a file named `CNAME` in the repo root containing just your domain, e.g. `yourdomain.in`. Commit and push.
3. At your domain registrar's DNS settings, add:

   | Type | Name / Host | Value |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | CNAME | `www` | `rahul-sah089.github.io` |

   Optional IPv6 AAAA records for `@`: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.
4. In **Settings → Pages → Custom domain**, enter `yourdomain.in` and save. Wait for the DNS check to pass (minutes to a few hours).
5. Tick **Enforce HTTPS** once it becomes available. The certificate can take up to 24 hours.

## 6. Search engines

**Google Search Console**
1. Go to https://search.google.com/search-console and add a **Domain** property (needs a DNS TXT record) or a **URL prefix** property for your site URL.
2. Verify ownership.
3. **Sitemaps** → submit `sitemap.xml`.
4. Use **URL Inspection → Request indexing** for the home page and your top 3–4 destination pages.

**Bing Webmaster Tools** (also feeds Yahoo and DuckDuckGo)
1. Go to https://www.bing.com/webmasters and sign in.
2. Choose **Import from Google Search Console** (fastest), or add the site manually and verify.
3. **Sitemaps** → submit `https://<your-site>/sitemap.xml`.

**Google Business Profile:** claim or create it, use the same name, phone and address as the site, and add the website link. Then put the profile URL in `config.js` (`social.googleBusiness`).

## 7. Project layout

```
index.html                    Home
fleet/                        Fleet overview
force-urbania-on-rent-bangalore/, tempo-traveller-on-rent-bangalore/,
luxury-maharaja-tempo-traveller-bangalore/          Vehicle pages
bangalore-to-*-tempo-traveller/                     17 destination pages
packages/ about/ contact/ privacy-policy/ terms/ links/ 404.html
assets/css/site.css           All styles (light + dark themes)
assets/js/config.js           ← business details, rates, destinations
assets/js/main.js             Theme, menu, WhatsApp forms, fare estimator
assets/img/                   Fleet photos, OG share cards
tools/generate.mjs            Rebuilds all pages from config.js
tools/make-images.mjs         Rebuilds OG cards, favicons, placeholders
sitemap.xml robots.txt site.webmanifest favicons
```

The `/links/` page is meant for your Instagram "link in bio".

Generated pages are committed to the repo, so GitHub Pages serves them as-is. Don't hand-edit the HTML files. Edit `config.js` or `tools/generate.mjs` and regenerate instead, or your edits will be overwritten.
